Practical 1: Build a branching model to help your team understand the Git 
workflow for faster integration of work. 
Step 1: Initialize Git Repository 
mkdir git-branching-demo 
cd git-branching-demo 
git init 
 
Step 2: Initial Commit 
echo "# Git Branching Demo" > README.md 
git add . 
git commit -m "Initial commit" 
 
Step 3: Create Develop Branch 
git branch develop 
git checkout develop 
git branch

Step 4: Create Feature Branch 
git checkout -b feature/login 
 
Step 5: Work on Feature 
echo "Login feature code" > login.txt 
git add . 
git commit -m "Added login feature" 
 
Step 6: Merge Feature into Develop 
git checkout develop 
git merge feature/login 
 
Step 7: Create Release Branch 
git checkout -b release/v1.0 
 
Step 8: Merge into Main 
git checkout main 
git merge release/v1.0
